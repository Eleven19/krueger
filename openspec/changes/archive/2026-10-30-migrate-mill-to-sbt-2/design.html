Context

See proposal.md for motivation. The active Mill graph has trees, core and compiler-api on JVM/JS/Native, compiler-api WebGC, two facade linkers, a JVM umbrella, a JUnit/Cucumber project and three combined API projects. Query code is inside trees. There is no independent testkit project.

Goals

Retain source layout, compiler diagnostics, versions, artifacts and existing workflow triggers. Avoid library changes and live release tests.

Decisions

BUILD-1. Explicit platform projects

Use sbt 2.0.11 with published sbt2 variants of Scala.js, Native and formatting plugins. Define explicit sibling projects with shared source roots instead of restructuring source files or introducing another cross-project plugin. Keep the umbrella artifact separate from the build aggregate.

TEST-1. Full qualification

Use testFull for CI/release qualification, with discovery checks before execution. Keep BDD as an actual project with Test sources and resources. Preserve JUnit platform suites and all Kyo framework variants. Incremental test remains available for iteration.

SITE-1. Uncached orchestration

Use checked artifact directories and uncached staging operations for external outputs. Validate producer files before replacing destinations, discard maps and references, stamp API HTML for Pagefind and rebuild npm sites in dependency order. This avoids treating an sbt task result as evidence that mutable external output still exists.

CI-1. Preserve categories and enforce aggregate

Keep lint, JVM/BDD, JS/browser, Native and docs categories with JDK 25. The baseline CI run 41001793667 succeeded in all five categories. Retain independent platform checks; add an always-running aggregate that rejects failed, cancelled and skipped dependencies. Release and Central promotion qualify their exact checkout with full tests. Retain approved triggers and secret names. Dependency caches accelerate resolution without replacing qualification evidence.

PUB-1. Stable Maven identity

Use VERSION-derived snapshot policy and explicit PUBLISH_VERSION overrides, preserve organization/artifact/platform suffixes and POM metadata, sign only in authorized publication jobs. Validate publishLocal and signed staging without remote release. Use maintained sbt2 publication plugins rather than implementing credential-bearing HTTP uploads.

Risks

Cached tests or empty discovery hide missing coverageExplicit discovery and repeated testFull runs.

Migration

Capture Mill baseline, add failing contract checks, migrate each producer and caller, run cold/warm qualification and local packaging, remove Mill after parity, then archive and land through protected PR checks. A revert restores the previous build without migrating library sources.
